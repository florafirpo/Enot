# Material de la cátedra

Notas de clase de Flora (explicaciones escritas a partir de las grabaciones) y la consigna del TP.
Son la base de conocimiento del agente revisor (`.claude/agents/companero.md`).

- `lineamientos.md` — **la rúbrica destilada**, con referencias a cada clase. Empezar por acá.
- `consigna-tp.md` — consigna oficial del TP integrador y criterios de evaluación.
- `clase-2026-08-13-introduccion.md` — qué hace un LLM, alucinaciones, contexto y contextos largos, RAG, tools, qué es un agente, system prompt, seguridad de datos.
- `clase-2026-08-20-programacion-asistida.md` — mapa de la programación asistida, niveles de abstracción, harness, problemas del vibe coding, changelog.
- `clase-2026-08-27-word-embeddings-1.md` y `clase-2026-09-03-word-embeddings-2.md` — word embeddings.
- `clase-2026-09-17-modelos-de-lenguaje.md` — de los n-gramas a los Transformers.
- `clase-2026-10-01-agentic-coding-sdd-ir.md` — agentic coding, archivos de reglas, SDD, ADR, verificación, tests significativos, mutation testing, guías/hooks/sensores, permisos, Information Retrieval (BM25, embeddings, RRF, evaluación) y knowledge graphs.
- `clase-2026-10-08-diseno-sistemas-agenticos.md` — gradiente de autonomía, ReAct, circuit breakers, diseño de tools, patrones de workflow y de agentes, skills, memoria, MCP.
- `clase-2026-10-22-langgraph-y-observabilidad.md` — APIs, LangGraph (estado, nodos, aristas condicionales, checkpoints), human in the loop, observabilidad con trazas (MLflow/Langfuse), comparación de diseños.
- `clase-2026-11-05-programas-y-entrenamiento.md` — programas como input/output/types, Software 2.0/3.0, optimización de prompts, costos.
- `clase-2026-11-12-inferencia-local-y-benchmarks.md` — inferencia local, cuantización, benchmarks orientados a tareas y scoring functions.

Para buscar algo puntual: `grep -n "palabra" docs/catedra/*.md`.
